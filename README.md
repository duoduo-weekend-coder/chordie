Chordie is a progressive web app that teaches you one piano chord per day over 30 days. Chords unlock sequentially as you complete each lesson, with an interactive piano keyboard to hear and practice what you learn.

## Features

- 30-day structured chord learning path
- Interactive piano keyboard with audio playback
- Progress tracking saved locally in your browser
- Installable as a PWA on mobile and desktop
- Works offline

## Getting Started

Open the app at **https://duoduo-weekend-coder.github.io/chordie/** — no install required. On mobile, you can add it to your home screen for a native app experience.
